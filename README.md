# 常用公文字体
## Common Chinese office fonts

> 执行标准：[《党政机关公文格式》（GB/T 9704-2012）](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=F3CC9BEF482524C895FDA7A08BB4A70E)，部分字体（字库）仅供非商业用途使用，如需商业用途使用，请自行联系字体（字库）厂商获取使用授权。

## 标题2号小标宋体字：方正小标宋gbk    方正小标宋简体

### 一级标题3号黑体字：黑体

#### 二级标题3号楷体加粗：楷体_GB2312

#### 正文用3号仿宋字：仿宋_GB2312


> 方正小标宋简体基于‌GB2312标准，支持6763个常用简体汉字；
> 方正小标宋GBK基于‌GBK标准，支持21003个字符，涵盖‌简体字、‌繁体字及‌生僻字。
> 若文档涉及繁体字或专业术语，GBK版本能避免缺字问题；
> 建议：校内电脑同时安装两种字体，避免因系统字库差异导致显示问题。
